名刺スキャン

撮るだけで iPhone の連絡先に追加
読み取り中…
名刺を平らに置き、文字が読める明るさで、枠いっぱいに撮ってください。裏面に英語表記があるときは裏面も読むとふりがなの精度が上がります。

確認・修正

「連絡先に追加」を押すと iPhone の連絡先カードが開きます。右上の「連絡先を作成」で保存されます。

履歴

設定

キーはこの iPhone の中（このページの localStorage）にだけ保存され、名刺の画像と一緒に Anthropic の API へ送られるだけです。他のサーバーには送りません。

キーは console.anthropic.com で発行できます。1 枚の読み取りにかかる料金は数円程度です。

つかいかた

  1. 右上の「設定」で Anthropic の API キーを入れる（初回だけ）。
  2. 「名刺を撮る」で撮影。裏面があれば「裏面も撮る」。
  3. 「読み取る」を押すと数秒で項目が埋まるので、間違いを直す。
  4. 「連絡先に追加」を押すと連絡先カードが開くので「連絡先を作成」。

仕組み

写真を長辺 1568px に縮小して Claude に送り、姓名・ふりがな・会社・部署・役職・電話・メール・住所・URL を JSON で受け取ります。それを vCard 3.0（iPhone が読める形式）に組み立てて開きます。

履歴はこの端末の中だけに残ります。まとめて .vcf に書き出せば、PC や別の端末にも取り込めます。
